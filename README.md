# POS-AriadnaGomez

Sistema de Punto de Venta y control de inventario desarrollado en Java para la papelería **La Escuelita**.

## Avance actual

Implementación de la interfaz.
Correcciones de errores en las siguientes ventanas:
* Inicio de sesión
* Gestión de productos
* Inventario
* Ventas
* Reportes

## Tecnologías utilizadas

El sistema fue desarrollado utilizando el lenguaje de programación Java, empleando NetBeans como entorno de desarrollo para la creación de interfaces gráficas. Para el almacenamiento de información se utilizó una base de datos relacional SQL Server.

* Java
* NetBeans
* SQL Server
* GitHub
